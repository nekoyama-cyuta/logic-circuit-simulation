# 論理回路シミュレーター

ブラウザで動く論理回路シミュレーターです。インストールもビルドも不要で、`index.html` をブラウザで開くだけで使えます。

## できること

- **部品**: 入力スイッチ・出力ランプ・クロック・AND / OR / NOT / XOR / NAND / NOR / XNOR・中継点
- **配線**: ピンからピンへドラッグ（クリック→クリックでも可）。接続済みの入力ピンからドラッグすると付け替え
- **シミュレーション**: 操作するたびに即座に再計算。フリップフロップなどの記憶回路にも対応し、発振するループは警告を表示
- **真理値表**: 入力スイッチの全組み合わせを自動で計算（10入力まで）
- **アセット**: 選択した部品を部品集として登録し、ドラッグで再利用。半加算回路などの標準アセット付き
- **編集**: 元に戻す / やり直し、コピー / 貼り付け / 複製、範囲選択、右クリックメニュー、グリッド吸着
- **保存**: ブラウザに自動保存。JSON ファイルへの書き出し・読み込み（旧バージョンのファイルも読み込み可）

操作方法の一覧は、画面右上の **?** ボタンから見られます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `css/style.css` | 見た目 |
| `js/components.js` | 部品の定義（ピン・論理関数） |
| `js/circuit.js` | 回路モデル・シミュレーション・保存形式・真理値表（DOM 非依存） |
| `js/shapes.js` | 部品の SVG 描画 |
| `js/editor.js` | キャンバスの描画とマウス / キーボード操作 |
| `js/history.js` | 元に戻す / やり直し |
| `js/assets.js` | アセットの保存とパネル |
| `js/ui.js` | ダイアログ・通知 |
| `js/main.js` | 全体の組み立て |
| `assets_starterAssets.json` | 標準アセット（元データ） |
| `js/starterAssets.js` | 上記から生成したファイル（`node tools/build-starter-assets.js`） |

## テスト

Node.js があれば、回路モデルのテストを実行できます。

```bash
node tests/run-tests.js
```
